# 自然辩证法概论｜2020修订版开卷复习

> 目标：不是重写一本教材，而是让纸质书成为能在考场快速定位、查阅、组织答案的工具。

**考试结构**：名词解释4×5分；简答2×15分；论述2×25分，合计100分。开卷允许携带的具体材料以任课教师规定为准。

**唯一教材底本**：《自然辩证法概论（修订版）》，殷杰、郭贵春主编，高等教育出版社2020年3月第2版，ISBN 9787040535136。OCR仅作检索辅助，关键表述、原书页码须与纸质书核对。

## 主线

`2020教材 → 章节与考点索引 → 知识卡片(K001…) → 题库(N/S/L) → 纸书标注清单 → 考场速查索引 → 模拟查阅`

- `00_项目说明/`：考试规则、外部资料与证据边界
- `01_教材索引/`：各章节入口、可排序的考点总索引
- `02_知识卡片/`：每个核心知识点一张卡，集中记录答案依据
- `03_题型题库/`：N=名词解释、S=简答、L=论述；题目链接知识卡片，避免复制答案
- `04_纸书标注/`：按页码执行纸书标记，产出考场速查索引
- `05_模拟复盘/`：测真实查找时间、答案完整度，回填索引

## 工作规则

1. 先核对教材页码和文字，再写答案；OCR错字和同学笔记中的猜测不可当教材原文。
2. 其他学校题目只作为可考主题线索；不把其“高频”直接当作我校概率。
3. 同一个知识点只维护一张K卡片；三个题型文件链接同一张卡。
4. 每完成一张卡，必须生成纸书标注动作；未落实到书上的电子笔记不算完成。
5. 先把30秒能定位的索引做准，再丰富论述案例。考试前按老师规定确认是否允许带打印索引或贴签。

## 立刻开始

打开 `01_教材索引/考点总索引.csv`，逐条核对纸质教材页码。完成后打开 `04_纸书标注/书本标注清单.csv`，在对应页的页边写K编号并放少量便签。最后完善 `04_纸书标注/考场速查索引.md`。

**重要**：此仓库是个人复习项目，不镜像整本受版权保护的教材。只保存自写摘要、题目来源链接和索引。外部OCR及扫描本保留来源链接，不默认拥有再分发许可。
