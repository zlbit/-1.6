## N-01｜5分｜科学观察

**题意（模拟）：** 什么是科学观察？简述其基本特点。

- **主题：** G014（候选）；K018（候选）。
- **主要证据：** P193，R2C-EV-OBS-01。教材把观察界定为有目的、有计划地感知自然状态客体的科学认识活动，并列出计划性、目标性和弱介入等特征。
- **补充证据：** P196，R2C-EV-OBS-07。观察受理论影响；这可防止把“观察”写成完全被动或绝对中立。
- **必须回答：** 定义；有目的、有计划；直接/间接观察分类可按题干选择；观察的理论渗透属性。
- **查书顺序：** P193先取定义和基本特点；题目涉及观察是否中立时跳到P196。
- **提纲：** 一句定义 → 两项核心属性 → 依题干补充观察类型或理论渗透。
- **页边词：** 目标计划／直接间接；跳P196：理论渗透。
- **证据边界：** 不由观察定义推出观察完全客观，也不由理论渗透推出观察事实毫无经验约束。

## S-01｜15分｜观察、实验、理论的关系

**原题：** “观察、实验、理论三者之间有何关系？”

- **题目身份：** Q-CSU20MAY-02；材料为仓库保存的2020年5月单页考试资料，卷面自称中南大学研究生考试，身份未独立认证；原题类别为简答题，15分。
- **主题：** G014（候选）；K018（候选）。K005仅作科学本质背景，不作主证。
- **直接证据：** P193-P198；R2C-EV-OBS-01至09；对应PDF209-PDF214，逐页图像核验。
- **必须回答：**
  1. 观察获取科学事实，具有目的、计划等特点；不能当作纯被动观看。
  2. 实验是在目的和物质手段支持下控制或改变对象条件获取信息，介入程度高于观察。
  3. 实验者、对象、仪器/工具和实验情境共同构成实验；可重复性是实验特征之一。
  4. 观察并非完全脱离理论；理论会影响观察问题、解释框架。
  5. 实验与理论双向作用：实验为理论发展和修正提供基础，理论也指导实验设计。
  6. 观察、实验、理论的相互作用随学科和发展阶段变化，不能画成固定单向流水线。
- **查书顺序：** P193观察 → P194实验定义、组成与重复性 → P195实验室人工条件 → P196理论渗透 → P197实验与理论双向作用 → P198三者关系随学科/阶段变化。
- **提纲：** 观察和实验的区别及联系 → 理论如何介入观察 → 实验与理论互相促进、互相约束 → 三者关系的多样性。
- **页边词：** 观察弱介入；实验强介入／人-对象-工具-情境；理论渗透；实验↔理论；三螺旋。
- **跨页调用：** 若设问改为“重复实验是否证明数据绝对客观”，回到P194-P197并明确教材没有给出该绝对结论。
- **证据边界：** 原题本身不问数据绝对客观性；教材页也不支持把可重复性直接等同绝对客观。若题目要求评价具体数据，还需仪器、材料和研究设计证据。
- **纸书状态：** 未执行；本轮未报告实体纸书查书测试。

## L-01｜25分｜技术发展模式与动力

**题意（模拟）：** 结合教材提到的“电磁感应定律与发电机的发明”，论述技术发展的动力结构，并评析技术自主论和社会建构论的解释限度。

- **主题：** G017（候选）；K022（候选）。
- **直接证据：** P130-P137；R2C-EV-TECH-01至09；对应PDF146-PDF153，逐页图像核验。
- **必须回答：** 区分技术发展模式与动力；说明社会需求与技术水平的基本动力关系、技术目的与手段的直接动力关系、科学进步和交叉融合的作用；准确概括技术自主论与社会建构论及教材所述局限；用教材举出的历史例子作有限说明。
- **查书顺序：** P130-P132社会需要、技术体系变动、科学先导 → P132-P133自主论/社会建构论及其局限 → P133-P135需求—水平、目的—手段 → P136-P137科学进步、交叉融合、文化因素及教材例子。
- **提纲：**
  1. 界定讨论对象，避免把科学发展模式和技术发展动力混为一谈。
  2. 先呈现两种国外理论，再指出各自看到的动力侧面与片面性。
  3. 以“社会需求—技术水平”解释基本动力，以“技术目的—技术手段”解释直接动力。
  4. 补入科学进步、交叉融合与文化环境等因素，形成多因素解释。
  5. 以教材所提电磁感应与发电机例子作简要照应，结论回到动力的相互作用。
- **页边词：** 基本动力：需求↔水平；直接动力：目的↔手段；自主论/建构论各有片面；科学交叉+文化。
- **案例边界：** P137可确认教材提及该历史例子，但本轮页证不支持补写教材未载明的具体人物、年代或完整因果链。若模拟要求展开现代案例，须另取可核验来源。
