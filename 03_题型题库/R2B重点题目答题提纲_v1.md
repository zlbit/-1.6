# R2-B重点题目答题提纲与查书顺序

本文件提供证据检索和组织路径，不是完整标准答案。案例、个人判断和题干材料仍按题目要求取证。

## 15分/问答：归纳与演绎（Q-CSU19-02、Q-CSU-A-02、Q-CSU22-10）

1. 先翻P145-P146：归纳定义、推理方向、特点、类型和或然性局限。
2. 再翻P149：演绎定义、一般前提到个别结论及有效推理条件。
3. 最后翻P152-P153：相互依存、补充与转化。
4. 依题型补充区别与联系；不要把一种方法写成另一种方法的充分替代。

## 15分：技术异化（Q-CSU19-05、Q-CSU-A-05；作者已实测K008）

1. P219：资本主义社会条件与自然/劳动者、机器、工人地位等表现。
2. P220：社会历史根源；机器本身与资本主义应用的区分。
3. P220-P223：法兰克福学派的现代技术社会批判。
4. P223-P224：与马克思分析的边界。
5. 具体预防路径若超出教材段落，单独标记外部依据，不把答题提示写作教材原文。

## 20/25分：生态自然观与生态文明（Q-CSU19-03、Q-CSU21-04、Q-CSU-A-03、Q-CSU22-17）

1. P66-P67取定义、生态系统组成与主要观点。
2. P68-P70取生态化创建及全球性、批判性、和谐性特征。
3. P73-P74取生态自然观对生态文明建设的作用。
4. 对接题干现实材料；题干未给的案例和政策数据须另找可核来源。

## 20分：科学技术与经济转型（Q-CSU19-04、Q-CSU-A-04）

1. P208-P212作为直接理论依据，抓科技、生产力和经济转型关系。
2. 题目要求的当代经济案例按时间和来源核验；当前知识卡未收集现实数据。
3. 若设问扩展到社会变迁或人类发展，再按题目需要跳转P213-P218。

## 20/25分：科学发展模式与动力（Q-CSU21-02、Q-CSU22-16）

1. P123-P125：发展总纲与内外动力。
2. P125-P127：逻辑实证、证伪、历史主义/范式转换的比较路径。
3. P129-P130：三种统一作为教材综合归纳。
4. 设问若改问“技术发展模式”，转R2-C2-10；该节点当前没有已核精确页。

## 25分：创新与人才（Q-CSU21-05、Q-CSU21-06、Q-CSU-A-06）

1. P320作为创新观入口；P337-P340查创新环境与人才内涵/作用/政策。
2. 用题干提供的案例组织分析；华为事实、创新能力不足的前提和因果判断当前均无外部核验。
3. 如题目要求创新型国家建设的具体体系，现有页码仅部分支持，需先补核第五章相应段落。

## 跨知识点选择题：马克思与现代技术批判（Q-CSU22-12）

- 先查K008 P220、P223-P224，区分马克思的机器本身/资本主义应用和法兰克福学派批判。
- 若题干明确问技术中立性或价值性，再查K014 P112-P113。
- 两者有关联，但不是同一知识点。

## 明确不能闭合的题

- Q-CSU22-11：P106-P107只能给科学活动/经验检验背景；第三章实验—理论关系页仍待核。
- Q-CSU22-13/14/15：分别有R2-C4-05、R2-C5-03、R2-C3-05检索路径，但当前没有图像核过的精确页。
- Q-CSU22-08：题干可辨，选项D转录不全；先回扫描原件补全文字。
