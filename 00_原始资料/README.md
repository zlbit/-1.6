## 本地导入PDF的建议检查

1. 安装并运行 `git lfs install`；从中南大学源仓库取回真实PDF（`git lfs pull`）。
2. 确认文件实际是PDF而不是LFS指针，检查封面版权页、页数和文件大小，再与纸质教材对页。
3. 在目标仓库执行 `git lfs track '00_原始资料/CSU/教材/*.pdf'`，连同 `.gitattributes` 与真实PDF一起提交推送。
4. 不要从OCR中凭空推算PDF页号。使用印刷页Pxxx；PDF物理页序建立单独映射表。
