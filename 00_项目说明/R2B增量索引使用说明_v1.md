# R2-B增量索引使用说明

1. 从题干中的概念名、同义词或描述性措辞查阅 `R2B主题关键词与检索路径增量_v1.csv`。
2. 先看对应G主题和K编号/矩阵节点，再看证据状态和“不可混同”边界。
3. 只把已核的印刷页码用于精确翻书；“无已核精确页”表示目前只有章节路径，不能据此圈具体段落。
4. N/S/L分别对应名词解释5分、简答15分、论述25分；答题提纲只规定取证顺序，不是标准答案。
5. 题目中的现实材料、个人判断或案例事实若未由题干提供，另找可追溯来源；外部资料不冒充教材原文。
6. 纸书执行单中新增圈划任务全部保持未执行。作者报告K006、K008已完成实测，其他知识点不因此自动改变状态。
7. 题目ID、原题正文状态和来源可信度以登记表为准。回忆题、答案汇编、扫描卷OCR和正式原卷不混为一类。
